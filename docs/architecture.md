# 架构

Chartloom 包含独立的 Python HTTP 服务和 React/D3 编辑界面。

| 目录 | 职责 |
| --- | --- |
| `src/chart_platform` | 文件解析、模型适配、转换流水线、校验、存储和 API |
| `web` | 上传、数据输入、图表编辑、组件绘制和导出 |
| `sdk/python` | 仅依赖标准库的 HTTP 客户端 |
| `themes` | 主题示例；`neutral` 为中性色，`om` 为浅色编辑主题 |
| `examples` | 使用合成数据的通用客户端示例 |
| `scripts` | 构建、启动、OCR 和源码发布检查 |
| `tests` | 合成数据与模拟模型响应的回归测试 |

图片和文档进入发现、提取、校验、布局、绘制与复核流水线。
数据创建模式直接读取原始表格，由模型选择字段及图型，再由程序绑定实际单元格。
模型不能为数据创建路径返回替代数值或可执行绘图代码。

每个任务保留原始文件或输入表格、来源、主题快照、版本、自动检查和调用用量。
保存使用修订号，防止旧窗口覆盖新编辑。SVG、PNG 和 Excel 导出使用同一版保存数据。
缺失值保持为空，估计值保留方法说明，自动转换结果与人工核对状态分别保存。

运行数据默认位于 `.runtime/data`，由使用者管理，不进入源码仓库。
独立服务默认供本机使用；外部应用通过 `/api/v1/` 和轻量 SDK 调用。
